# Core Lib

A core library for modifying Sandustry.

## Usage

To learn how to use corelib you must see the example repository. Copy paste the lines below for intellisense support in their respective environments.

Electron

```js
/** @typedef {import('../corelib/entry.electron.js')} */
```

Worker

```js
/** @typedef {import('../corelib/entry.worker.js')} */
```

Game

```js
/** @typedef {import('../corelib/entry.game.js')} */
```
